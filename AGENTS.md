# Rotina AI — Project Context

## Product Vision

Rotina AI is an AI-powered productivity and life management platform focused on helping users build, maintain and adapt their routines intelligently over time.

The product is not just a habit tracker or calendar. The main idea is to create a system that behaves like a personal operational copilot — an intelligent assistant capable of understanding the user’s context, energy, goals, limitations, routines and behavioral patterns to continuously optimize their daily life.

The platform should feel personal, adaptive, dynamic and alive.

The experience should resemble a premium mobile app rather than a traditional corporate dashboard.

The long-term vision is to become a daily companion that helps users:
- organize routines
- improve consistency
- reduce procrastination
- manage energy and focus
- optimize schedules
- balance health/study/work
- receive AI-generated guidance
- adapt plans dynamically
- maintain discipline sustainably

The product combines concepts from:
- productivity apps
- habit trackers
- AI assistants
- behavioral systems
- personal analytics
- adaptive scheduling
- coaching systems
- intelligent planning

---

# Core Product Philosophy

The product must avoid looking robotic or spreadsheet-like.

The AI should feel:
- contextual
- supportive
- intelligent
- realistic
- adaptive
- proactive

The system should not generate unrealistic “perfect routines”.

Instead, it should:
- adapt to real human behavior
- understand energy fluctuations
- understand failures and inconsistency
- reorganize plans dynamically
- offer alternative plans when needed
- continuously improve recommendations

The platform should prioritize:
- simplicity
- retention
- emotional engagement
- usability
- mobile-first UX
- habit formation psychology

# Main Product Features

## 1. Intelligent Routine Generation

Users provide:
- goals
- wake/sleep times
- fixed commitments
- available time
- energy levels
- personal preferences
- productivity style
- current struggles

The AI generates:
- daily routines
- study blocks
- workout scheduling
- deep work periods
- rest periods
- adaptive weekly planning

The generated routines must feel realistic and personalized.

---

## 2. Dynamic Routine Adjustment

The system should support dynamic adaptation.

Examples:
- user slept badly
- user skipped tasks
- user is mentally exhausted
- user lost motivation
- unexpected event occurred
- schedule changed

The AI should:
- reorganize blocks
- reduce overload
- suggest alternative plans
- recalculate priorities
- redistribute tasks

The system should behave more like a smart adaptive planner than a static schedule app.

---

## 3. AI Assistant / Copilot

The platform includes an AI assistant/chat interface.

The assistant should:
- help organize the day
- answer productivity questions
- suggest schedule improvements
- motivate the user
- explain behavioral patterns
- recommend focus strategies
- generate plans
- summarize progress
- assist in decision-making

The assistant should have contextual awareness of:
- current routines
- habits
- user goals
- weekly progress
- energy patterns
- check-ins
- recent activity

---

## 4. Daily Check-ins

Users can submit daily feedback such as:
- energy level
- mood
- focus level
- sleep quality
- stress level
- obstacles
- important events

The AI uses this information to adapt routines and recommendations.

---

## 5. Habit Tracking

Users can:
- create habits
- track consistency
- visualize streaks
- monitor completion rates
- categorize habits

The UI should feel modern, clean and motivating.

---

## 6. Insights & Analytics

The system should analyze:
- consistency
- focus patterns
- productivity windows
- habit success rates
- common failures
- behavioral trends

The platform should present:
- intelligent insights
- weekly summaries
- behavioral patterns
- suggestions for improvement

The analytics should feel human and useful, not overly technical.

# Important Development Rules

- Build mobile-first
- Prefer reusable components
- Keep architecture scalable
- Avoid hardcoded business logic in UI
- Separate UI, features and mock data
- Keep components clean and composable
- Prepare project for future API integration
- Focus on UX and retention
- Simulate realistic user flows
- Avoid generic dashboard templates
